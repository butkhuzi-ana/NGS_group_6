# Transcriptomic and Pathway Analysis of TNBC and ER+ Breast Cancer

This project presents a transcriptomic analysis of Triple-Negative Breast Cancer (TNBC) and Estrogen Receptor-Positive (ER+) breast cancer samples using publicly available RNA-seq data from the study by Varley et al.

The main objective of this analysis is to identify differentially expressed genes between the two breast cancer subtypes and to explore associated biological pathways and functional enrichment patterns.

### Data source
The dataset used in this project originates from a publicly available breast cancer RNA-seq study by Varley et al. titled “Recurrent read-through fusion transcripts in breast cancer” published in Breast Cancer Research and Treatment (2014). The genomic data is stored in RangedSummarizedExperiment - in a Bioconductor object.


***This project was developed as part of a Next Generation Sequencing course project by Ana Butkhuzi and Ericka Garcia.***
